Material findings reflected in the brief
1. Current runnable target is a Babylon.js/TypeScript browser prototype. main.ts
   constructs Babylon Engine, not WebGPUEngine. WebGPU is a direction, not a
   verified currently deployed capability.
2. The current tour manifest specifies 210 seconds and six story/evidence stops.
   Earlier documentation mentions 180 seconds, 2-5 minutes, or 3-9 minutes.
   The brief uses the current configured value and avoids invented visitor metrics.
3. The Evidence UI exposes claim confidence, reconstruction notes and source links.
   This supports an evidence-transparency proposition; it does not establish that
   every reconstruction has received independent scholarly approval.
4. The internal toggleNarrator name currently controls the soundscape. Authored
   narration is not described as a finished feature in the investor brief.
5. The app requests WebXR via the browser and Babylon's default XR experience.
   Full headset compatibility, three validated locomotion modes and comfort
   certification have not been demonstrated by this review.
6. Unreal is a project shell with a planned import bridge. Unity is a reserved
   adapter. Shared content contracts are implemented; a shared production engine
   across all three runtimes is not established.
7. The visual roadmap and supplied product screenshots show the main remaining
   quality gap: physical material response, ground repetition/banding, convincing
   contact shadows and character fidelity. Preserve the locked district and
   canonical camera; polish the existing hero street before expanding the world.
8. No billing, subscription, login or commercial analytics implementation was
   located in the browser source search. No customer, revenue, signed partnership,
   team, fundraising amount or unit-economics evidence was supplied. Commercial
   models in the brief are proposals, not existing revenue streams or forecasts.

Brand concept
ANCIENT MEMPHIS / WALK INTO HISTORY
An original geometric gateway welcomes the visitor; a sun suggests warmth and
discovery; a river line connects the identity to the Nile. It is a modern brand
symbol, not a claimed ancient Egyptian hieroglyph. The experience subtitle stays
'A Walk Through the White Walls'; Egypt VR Tour remains the project identity.
Palette: Nile charcoal #152D30; sun gold #B78745; warm ivory #F6F1E7.
The vector uses editable Georgia/Segoe UI text; outline the text in a vector
editor if a future print supplier requires font-independent artwork.

Reference handling
All 14 supplied Memphis reference images appear in the PDF, as do the three
supplied application screenshots. Reference images are fitted intact and retain
visible creator marks; they are labelled as aspirational, not runtime output.
Several portray other periods or artistic/fantastical architecture. They should
guide mood rather than determine the Early Dynastic / Old Kingdom historical plan.
Media ownership/redistribution rights were not established; the PDF records that
public promotion should use cleared or project-owned material.

Suggested next production step

hero street. Agree a target device matrix, then measure completion, visual
response and support effort in a small paid institutional pilot. Set fundraising
size and schedule from that scoped plan rather than from speculative forecasts.
