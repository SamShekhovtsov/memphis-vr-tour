# Dry-soil source material

Asset: Brown Mud Dry, by Rob Tuytel, from Poly Haven.

- Source: https://polyhaven.com/a/brown_mud_dry
- Licence: CC0-1.0, verified 2026-10-24 at https://polyhaven.com/license
- Original scale: approximately 1.3 metres across.
- Official download metadata: files.json. Downloads were checked against its MD5 values; the generated ground manifest additionally records SHA-256 hashes.

The project uses this as generic physical soil material, not archaeological
evidence for a specific Memphis street. The selected source has no recognizable
modern footwear or litter. Compaction, disturbed-earth, deposit and shallow
bare-foot masks are project-authored artistic reconstruction.

The OpenGL normal source is retained for reference. The runtime normal is derived
from the matched height channel after spatial blending and compaction, preserving
alignment with the resulting albedo and roughness. No mesh displacement is used.
